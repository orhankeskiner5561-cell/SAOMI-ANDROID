# ŞAOMİ Battle Royale RC3 Lobby

RC3, önceki kutu karakterli OpenGL prototipinden ayrılan yeni Godot 3D lobi hattıdır.

- Rigli erkek ve kadın gerçek humanoid meshleri
- Podyum lobi
- 360 derece döndürme
- İki parmak zoom
- Erkek / kadın seçimi
- Saç, kıyafet, şapka, çanta ve silah slot altyapısı
- Tekli / 4 kişilik takım seçimi
- Maç başlamadan karakter hazırlama ekranı

Karakter tabanı: Quaternius Universal Base Characters (CC0).
Bu RC3 gerçek humanoid mesh kullanır; tasarlanan fotogerçekçi konseptin birebir özel modeli henüz değildir.
